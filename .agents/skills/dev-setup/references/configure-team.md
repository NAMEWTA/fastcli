# 按需保存团队配置

用户要求创建、修改或整理一组协作约定时，交付一份可显式引用的 Markdown。团队文件组织角色、模型偏好、成本预算和交付约定；保存本身不启动 Agent、不强制复核，也不改变宿主配置。

## 文件与选择

1. 用户给出文件或团队名时沿用。新建时默认放 `.agents/dev/context/team/<team_name>.md`；没有名称就从本次 topic 生成简短的单段名称，例如 `capture-annotations.md`。去除路径分隔符、父目录跳转和平台非法字符，检查实际重名；更新既有团队沿用原文件，创建不同团队时使用可辨识后缀，不能覆盖另一个团队。
2. 用户只要求环境初始化时不创建团队文件。用户只要求保存约定时只保存；在后续任务明确引用某个文件时，才把它作为本次任务上下文读取。不同文件独立存在，不设项目默认组，不扫描整个目录合并规则，不写入根指令的自动加载入口。
3. 一次明确引用多份文件时，保留各自适用范围；有实质冲突且本次指令不能消解时，只询问那个冲突。任务与交接传递已选文件的真实位置和必要内容；新任务没有显式引用时不继承上次选择。
4. 用户要求整理已有角色文件时，先读取并保留自定义条目、预算、未确认项和规则语义，再按主题拆分；写后回读并核对覆盖范围。历史文件及其根导航只在本次迁移授权覆盖时调整，不因安装技能就搬迁或删除项目资料。

## 核对实际能力

核对准备使用的 CLI/宿主版本、实际模型和推理参数；只有可靠的当前枚举或配置证据才写入真实标识。不猜测某模型在所有账户或宿主中可用。没有枚举时保留继承或未确认，不填看似真实的默认值。

`inherit-parent`、`auto` 可用于表达本地继承意图，但不保证是工具接受的枚举。调用时按实际 schema 省略覆盖字段，或使用该宿主支持的继承方式。文件普通文本与原生配置不是同一种接口；只有用户另有明确要求时，才修改已核实的原生设置并验证其作用域。

已有角色表只约定实际启用的角色。用户列出模型、候选池或角色名不自动触发实施、分工或复核。保留自定义或尚不明确的角色；删除受管理的退役条目时说明变化。移除某个覆盖表示恢复当前宿主继承语义，不恢复历史默认模型。

## 记录成本与推理预算

用户已给定预算或模型时直接沿用。缺失时保持当前设置；只有实际选择会改变成本或结果且无法从现有约定解决时，才问一个具体问题。以下仅是沟通标签，不是可直接传入的跨宿主枚举：

| 预算意图 | 表达方式 |
| --- | --- |
| 用户允许较充分推理 | 在本次工具实际支持范围内使用已选的高推理等级 |
| 成本与质量平衡 | 使用用户认可的中间档或当前继承设置 |
| 较低成本与延迟 | 使用已确认的较低档或用户指定的经济模型 |
| 未指定 | 继承当前会话与工具设置 |

若宿主明确支持 `max > xhigh > high > medium > low`，可在同一模型家族内选择不高于用户目标的最高可用等级；不存在该顺序或对应关系时不套用。模型标识与独立推理参数按真实接口处理，不拼接出不存在的名称。速度选项同样核对实际字段。

例如某家族只支持 `high` 与 `medium`，较高目标最多落到已确认的 `high`；另一个家族的可用上限不能推广给它。继承条目保持继承。模型不可用时只采用用户已允许的回退，否则保留原约定并说明缺口，不擅自提高成本。

## 组织角色与交付

使用[团队模板](../assets/team.md)，只保留当前团队实际需要的角色与产物。可按用途组织实现与重构、缺陷修复、性能调查、探索与讲解、历史调查与综合、判断与复盘、并行工作者、方案候选、交叉裁判或独立评审；不预建一套所有项目必填的角色。

- 为每个启用角色记录 CLI、模型或继承、推理意图、能力来源、需要的总数量与选择理由。角色变化要能与用户要求对回。
- 评审列表的每项代表需要的独立判断视角，重复继承项也计入数量；数量不是同时运行额度。调度遵守当前环境预算，顺序完成可以保留覆盖，不能虚报并发或跨模型独立性。
- 交叉裁判候选池按偏好选择实际可用且满足独立性要求的一项；没有符合要求的不同家族或独立上下文时，明确局限。模型名不同本身也不证明证据独立。
- 协作规则写出实际触发条件和交付证据。例如用户要求公共接口变化须独立复核，则记录这个条件与对应版本证据；没有接口变化不额外强制该步骤。
- 已有规格、验收和主机资源记录只引用权威位置，不在每份团队文件复制一套固定并发或容量。团队文件不取代资源准入。

## 保存与验证

只修改用户本次指定的配置范围。保留可恢复版本和其他自定义内容，写后回读实际文件，核对名称、用途、条目和链接。模型/推理组合只报告已确认或未确认；需要真实调用验证时按授权在资源预算内完成。

交付文件位置、角色或规则变化、能力核验结果和未覆盖项，并给出显式引用方式，例如“本次按 `.agents/dev/context/team/capture-annotations.md` 协作”。只保存时明确已保存，不声称工具自动加载或新会话已经生效。
